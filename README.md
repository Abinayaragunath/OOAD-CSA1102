## Passport Management System

The Passport Management System is designed to simplify the passport application and verification process. The applicant submits the passport application and provides the required details to the Passport Office. The Passport Office forwards the applicant's information to the Central Computer for verification.

The Central Computer verifies the applicant's details using the stored records and sends an approval or rejection result to the Passport Office. If the application is approved, the Passport Issuing Officer issues the passport to the applicant.

### Main Functions
- Submit Passport Application
- Provide Applicant Details
- Forward Details to Central Computer
- Verify Applicant Details
- Retrieve Applicant Records
- Approve or Reject Application
- Receive Verification Result
- Issue Passport
